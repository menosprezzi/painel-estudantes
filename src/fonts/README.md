# Fontes locais

## Host Grotesk

Os arquivos WOFF2 desta pasta são a distribuição oficial do Google Fonts indicada pela [Element Type](https://elementtype.co/host-grotesk/), autora da família. Foram obtidos em 30 de setembro de 2026 e são hospedados junto ao site, sem requisições de fontes a terceiros no navegador.

- Projeto original: [Element-Type/HostGrotesk](https://github.com/Element-Type/HostGrotesk).
- Licença: SIL Open Font License 1.1, reproduzida integralmente em `OFL-Host-Grotesk.txt`, obtida do projeto original. Permite uso, incorporação e redistribuição sob seus termos; mantenha este aviso e a licença ao redistribuir os arquivos.
- Autoria: Doğukan Karapınar / Element Type; mastering de İbrahim Kaçtıoğlu; baseada em Poppins.
- Formato: WOFF2 variável, pesos 300–800, estilos normal e itálico, subconjuntos Latin e Latin Extended.
- Os binários não foram modificados. Os nomes locais apenas identificam família, subconjunto e estilo.
- A interface usa `font-display: swap` e mantém Arial e fontes sans-serif de sistema como alternativas.

## Trechos de código

Os comandos usam a fonte monoespaçada disponível no sistema (`ui-monospace`, SFMono-Regular, Menlo, Consolas ou equivalente). Source Code Pro não está incluída no projeto.
